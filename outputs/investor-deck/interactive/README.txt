ManySight interactive investor deck

Run locally from this directory:

  python -m http.server 8080

Then open:

  http://localhost:8080

Navigation:
- Arrow keys / Page Up / Page Down: change slides
- F11 or the fullscreen button: present full screen
- On slide 6: drag and scroll to orbit; select Walk mode and use arrows or WASD
- Toggle cameras, semantic overlays, tracks and heatmap

The Three.js runtime is vendored under vendor/, so the interactive scene works offline.
